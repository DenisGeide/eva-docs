# Поиск товаров и ссылки

Ева может искать другой товар по просьбе покупателя. Найденная похожая вещь — предложение посмотреть, а не доказательство нужного размера, состава или свободного остатка.

## Как устроен поиск

В проекте есть детерминированный поиск каталога: это обычный программный подбор по признакам, которому не нужна модель для каждого сравнения.

Он нормализует текст, учитывает варианты слов, синонимы, тип вещи, названия, цвет и явно указанный код. Поиск по коду отделён от поиска по описанию. Данные о размере и количестве проверяются по вариантам, а не извлекаются как истина из рекламного текста.

| Этап | Что проверяется |
| --- | --- |
| Понять запрос | Какая вещь нужна; «похожее» может относиться к текущему товару |
| Найти кандидатов | Тип, слова и другие признаки каталога |
| Проверить соответствие | Не приписывать найденной вещи свойства соседнего товара |
| Подготовить ссылку | Публичная подтверждённая ссылка относится к точному объявлению |
| Обсудить покупку | Актуальные свободные варианты и правильный контекст объявления |

## Почему важно перейти в нужное объявление

Чат Авито остаётся связанным с объявлением, из которого написал человек. Упоминание другой вещи не переносит на неё цену, остаток, резерв или заказ.

Учебный пример: из объявления куртки просят показать брюки. Ева может предложить найденные варианты и их подтверждённые публичные ссылки. Для действий с выбранными брюками нужен правильный контекст и свежие данные именно этой вещи.

Историческое описание навигации ограничивает такую подборку несколькими вариантами, обычно до трёх. Это не обещание полного поиска по всем предложениям площадки.

## Что не следует обещать

- Количество из поискового индекса не является проверенным живым остатком.
- Похожее фото не подтверждает точную модель и замеры.
- Ссылка не должна выдумываться или указывать на другой размер ради оплаты.
- Отсутствие подтверждённой активной ссылки нельзя скрывать предложением оформить чужой вариант.

Поиск выполняется по доступному каталогу проекта, а не по всему интернету. При отдельном уточнении характеристик точной модели может использоваться официальный источник — это другая задача, с собственной проверкой соответствия.

**Подтверждение:** модуль поиска и описание навигации между карточками. [Источники](sources.md).
