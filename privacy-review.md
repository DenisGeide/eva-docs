# Проверка безопасности и приватности

**Дата проверки: 12.11.2026. Область: все публикуемые файлы этого documentation-only репозитория.**

## Что разрешено публиковать

Markdown-страницы, проверенные изображения бренда и интерфейса, описание их происхождения и минимальный JSON с агрегатами. Исходников приложения, скриптов управления и установочного пакета здесь нет.

## Что исключено

| Категория | Решение |
| --- | --- |
| Production-код и полные внутренние инструкции | Не копировались |
| Базы, dumps, backups и полные отчёты | Не включены; использованы только выбранные агрегаты |
| Ключи, токены, пароли, credentials, секретные конфигурации | Не включены; значения не нужны для описания системы |
| Переписка, имена, контакты, адреса и номера заказов покупателей | Не публикуются; все текстовые примеры вымышлены |
| Buyer/chat/message/listing ID и внутренние коды реальных товаров | Значения не публикуются |
| Приватные адреса, IP и абсолютные пути | Не публикуются |
| Полный архивный скриншот сверки | Исключён, поскольку нижняя часть содержит внутренние коды |
| Приватный журнал исследования | Хранится вне репозитория |

## Изображения

- `stock-overview-archive.png` — только верхняя область настоящего архивного интерфейса. Нижняя область с кодами товаров полностью исключена из публикуемого файла.
- `conversation-demo.png` — учебная сцена сайта. Реальные покупатели и их данные в неё не переносились; подпись не выдаёт её за production-снимок.
- `eva-logo.png` — знак Евы из предоставленного визуального материала, отрисованный в локальном представлении бренда.
- `toventra-logo.png` — актуальный бренд программы: тот же исходный знак и надпись Toventra из отдельного frontend. Только бренд, без интерфейса или персональных данных.

При обновлении бренда 12.11.2026 учебная сцена заменена снимком нового отдельного сайта Toventra. Куртка на нём — сгенерированная иллюстрация. Подписи явно указывают на демо; изображение не используется как доказательство наличия, характеристик или отправки реального товара. Настоящий архивный скриншот сверки сохранён без изменений.

Изображения просматриваются отдельно: текстовый поиск не умеет надёжно находить персональные данные внутри пикселей. Проверяются и служебные PNG-метаданные.

## Метод проверки

1. Инвентаризация всех файлов, включая скрытые; отдельная проверка перечня для Git.
2. Разрешающий список типов и конкретных вложений.
3. Поиск признаков credentials, приватных адресов, абсолютных путей, длинных идентификаторов, контактов и случайных source/database/config файлов.
4. Ручное чтение Markdown/JSON и визуальный просмотр изображений.
5. Проверка ссылок, навигации, Mermaid и соответствия публичных агрегатов выбранным источникам.
6. Перед публикацией проверяется именно будущий Git-снимок. Игнорирование файла не считается обезличиванием его содержимого.

Стандартные Git-метаданные создаются отдельно от публикуемых файлов; секреты доступа в них не сохраняются. Проверка не является гарантией обнаружения любого возможного секрета и должна повторяться при каждом добавлении материала.
